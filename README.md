# GX6605S / StarSat SR-4040HD Vega Emulator for macOS

A native macOS emulator, debugger, and firmware workbench for **NationalChip GX6605S** (C-SKY ABIv1 `CK610M`) satellite receivers—developed and tested with **StarSat SR-4040HD Vega** firmware.

It combines a **C-accelerated C-SKY ABIv1 interpreter** (`~64 MIPS`), a **Python hardware/SoC model**, and a **SwiftUI macOS app (`StarSat Emulator.app`)** with live `1920 × 1080` OSD rendering, NEC infrared remote control, **Fast Boot** snapshot caching, and a collapsible low-level debugger.

> **Included Binary & Disclaimer**: Proprietary receiver firmware dumps, OTP/security-bank captures, and backups are **not** included in this repository (and are excluded via `.gitignore`). The open-source [SR-4040HD_VEGA_chip8_console.bin](custom_firmware/SR-4040HD_VEGA_chip8_console.bin) homebrew binary is included so you can boot and test the emulator immediately out of the box.

## Features

### 1. Native macOS Desktop App (`StarSat Emulator.app`)
- **TV-First Dark UI**: Centered `16:9` OSD viewport with a dedicated remote pad (`POWER`, `MUTE`, `MENU`, `EXIT`, `▲/▼/◀/▶`, `OK`, `VOL+/VOL-`, `INFO`, and custom 32-bit NEC hex input).
- **Full Screen Mode (`⌘F`)**: Distraction-free OSD view with a compact floating remote strip.
- **Fast Boot Snapshot Cache**: Caches the post-boot OSD-ready state in `/tmp/starsat_boot_cache/` (keyed by firmware SHA-256 and profile) so subsequent boots jump straight to the live OSD in under a second.
- **Collapsible Inspector (`⌘I`)**: Segmented drawer for **Serial UART** (live TX/RX), **CPU Registers**, **Disassembly**, **Memory & Breakpoints**, **Profile Assumptions**, and **JSON Report Export**.

### 2. GX6605S SoC & C-SKY ABIv1 Emulation (`starsat_emu/`)
- **C-Accelerated Execution (`native/csky_fast.c`)**: Runs integer/RAM instructions in compiled C (`_csky_fast.dylib`) with exact Python fallback boundaries for MMIO, TLB/CP15, interrupts, and tracing, plus batched I2C NACK polling for both the bootloader and eCos runtime (`~64 MIPS`).
- **Graphics & Display (`video.py`, `graphics.py`, `av_mcu.py`)**:
  - Software scanout of GX6605S OSD descriptor lists (up to `1920 × 1080`, ARGB8888/RGB565/indexed).
  - 2D Graphics Accelerator (GA) copy/blit execution (`0x04800000` / IRQ 62).
  - Behavioral Chips&Media BIT/GDI VPU command handling (`FIRMWARE_GET`, `DEC_SEQ_INIT`, `DEC_SEQ_END`) and bring-up stubs (`receiver-runtime` profile) that boot the real StarSat OSD menus.
- **Infrared Remote (`CIR` @ `0x00204000`, IRQ 4)**: Encodes 32-bit NEC pulse frames into the 33-word GX6605S CIR FIFO, verified against the receiver's `0xbfbf` RCU keymap.
- **Peripherals**: UART (`115200` baud), SPI NOR flash (read-only/volatile overlay—never writes to source `.bin` or hardware), Timer-0 IRQ (IRQ 10), RTC, GPIO, I2C, EHCI/OHCI reset & status, and read-only OTP.

### 3. Firmware Workbench & Homebrew Tools (`tools/`)
- **Clean-UI Firmware Theme Builder (`tools/build_clean_ui_firmware.py`)**: Unpacks the firmware's CramFS partition, restyles 29 UI assets inside `theme/bmp.bin` (dock, floating labels, submenu cards, info banners, alert dialog, and icon tiles) into a flat dark-slate/cyan theme, recalculates the CramFS CRC32, and outputs a testable duplicate image without touching recovery backups.
- **Standalone CHIP-8 Game Console (`tools/build_chip8_firmware.py`)**: Assembles a self-contained `1,252`-byte native C-SKY ABIv1 CHIP-8 VM + **Brickout** ROM with a `aa55aa55` GX6605S boot header (`640 × 360` ARGB8888 OSD + CIR IR input). Boots in under a second in `StarSat Emulator.app`.

## Quick Start

### Prerequisites
- **macOS 13+** with Xcode Command Line Tools (`clang`, `xcrun swiftc`)
- **Python 3.9+** (standard library only—no `pip` packages required)

### Build & Run the macOS App
```sh
sh tools/build_macos.sh
open "StarSat Emulator.app"
```
1. Click **Open…** and select either your own GX6605S `.bin` dump or a homebrew image generated by `tools/build_chip8_firmware.py`.
2. Keep the **OSD Runtime** (`receiver-runtime`) profile selected.
3. Click **Run** (or **Fast Boot** once cached) and use the **Remote** pad (`MENU`, `OK`, `EXIT`, arrows) or **Full Screen (`⌘F`)**.

### Generate Homebrew or Clean-UI Images
```sh
# Build the standalone CHIP-8 Brickout console (.bin output in custom_firmware/)
PYTHONPATH=. python3 tools/build_chip8_firmware.py

# Build a dark-slate/cyan rethemed duplicate from your recovery flash dump
python3 tools/build_clean_ui_firmware.py
```

### CLI & Tests
```sh
# Inspect a firmware image and CramFS checksums
python3 -m starsat_emu inspect path/to/firmware.bin

# Disassemble instructions
python3 -m starsat_emu disasm path/to/firmware.bin --start 0x100040 --count 24

# Run headless with a step budget and JSON report
python3 -m starsat_emu run path/to/firmware.bin --profile receiver-runtime --max-steps 100000000 --report out.json

# Run the full unit test suite (188 tests)
python3 -m unittest discover -s tests -q

# Native app smoke test
'./StarSat Emulator.app/Contents/MacOS/StarSatEmulator' --self-test
```

## Profiles

| Profile | Purpose |
| :--- | :--- |
| `receiver-runtime` | Default desktop profile with VPU command handling, GA blits, CIR IR, and Audio/Demux/Demodulator bring-up stubs to reach the live OSD menus. |
| `receiver-observed` | Uses CRC-checked hardware register & OTP/security-bank captures without experimental runtime stubs. |
| `exploratory` | Minimal zero-initialized exploratory profile for early bootloader analysis. |
| `strict` | Zero unverified reset assumptions; stops immediately on unknown peripheral reads. |

## Compatible Receivers

The emulator targets **NationalChip GX6605S** (C-SKY ABIv1) receivers using unencrypted `aa55aa55` SPI flash dumps or `.bin` update images (offset `0x0` or `0x100`).

### Verified & Tested
- **StarSat SR-4040HD Vega** — Full 4 MiB SPI flash dump, V3.93 update image, OSD menus, and `0xbfbf` NEC remote keymap.
- **Custom GX6605S `aa55aa55` Homebrew** — Open-source [SR-4040HD_VEGA_chip8_console.bin](custom_firmware/SR-4040HD_VEGA_chip8_console.bin) included in this repository.

### GX6605S Hardware Family (Untested — Likely Compatible)
Other DVB-S2 receivers built on the same **GX6605S** SoC (often with 4 MiB `25Q32` SPI flash and eCos firmware) may boot or reach the OSD if their image is unencrypted and uses the `aa55aa55` boot header, though board-specific GPIO, front-panel, or remote keymaps can differ:
- **StarSat**: [SR-400HD Pro](https://dwdvb.com/starsat-sr-400hd-pro/), [SR-488 Vega](https://masrysat.com/threads/60021/), [SR-480HD Extreme](https://www.youtube.com/watch?v=b-IvHX80C_Y)
- **Tiger**: [Tiger F1 HD](https://antena.md/ru/tiger-f1-receptorul-mult-asteptat/), [Tiger New T530](https://av-sat.com.ua/ua/p864290172-kombinirovannyj-dvb-t2s2.html), [Tiger T90 / T245 Ultra](https://www.youtube.com/watch?v=b-IvHX80C_Y)
- **Géant / Eurosky / Generic GX6605S Boards**: [Géant R4 Mini Plus](https://www.youtube.com/watch?v=b-IvHX80C_Y), [Eurosky ES-19](https://av-sat.com.ua/ua/p864290172-kombinirovannyj-dvb-t2s2.html), [GX6605S HW203](https://khandishnetwork.net/gx6605s-hw203), [Star-LED SR-4040HD Extreme (`GX6605S-MINI70`)](https://dumpdz1234.blogspot.com/2021/06/dump-star-led-4040-hd-extreme-carte.html)

*(Receivers based on other SoCs such as ALi, Sunplus, GX6607H1, or Amlogic are not supported.)*

## Current Limitations
- **OSD-only display**: Renders the `1920 × 1080` OSD menu layer; MPEG-2/H.264 video-plane decoding and audio output are not implemented.
- **No DVB-S2 RF / Wi-Fi / USB HID**: Tuner/demodulator and EHCI/OHCI controllers do not attach physical USB dongles or live satellite/network streams yet.
- **Verification**: All tests and UI verification are against the emulator's software models; flashing custom images to physical hardware is always at your own risk—keep a full SPI flash backup and RS232/CH341A recovery option handy.

- `native/StarsatApp.swift` — SwiftUI macOS frontend

- `starsat_emu/` — Python CPU, MMU, bus, peripherals, OSD renderer, and CLI/bridge
- `tools/` — C-SKY assembler, CHIP-8 console builder, clean-UI theme builder, and serial diagnostics
- `tests/` — 188 unit & differential tests
- `docs/` — Boot status, graphics/AV notes, and primary hardware references
